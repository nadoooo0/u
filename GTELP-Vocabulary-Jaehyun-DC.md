## 디시 갤러리 "동의어를 따로 외우기 vs 기출 7개 풀면서 정리하기" 결론

### 기출에서 자주 겹치는 동의어 쌍 (TOP 20)

1. **accomplish - achieve**: 둘 다 "성취하다" 의미 但 accomplish는 어려운 목표, achieve는 노력으로 얻는 것
2. **abundant - plentiful**: 모두 "풍부한" 의미
3. **adequate - sufficient**: 모두 "충분한" 의미 但 adequate는 "적절한" 뉘앙스
4. **adverse - unfavorable**: 모두 "불리한" 의미
5. **assist - support**: 모두 "돕다" 의미
6. **authorize - empower**: 모두 "권한을 주다" 의미
7. **beneficial - advantageous**: 모두 "이익이 되는" 의미
8. **comprehensive - thorough**: 모두 "철저한" 의미
9. **consecutive - successive**: 모두 "연속적인" 의미
10. **construct - build**: 모두 "건설하다" 의미
11. **contribute - provide**: 모두 "제공하다" 의미
12. **deteriorate - decline**: 모두 "악화되다" 의미
13. **diminish - decrease**: 모두 "감소하다" 의미
14. **discharge - release**: 모두 "해제하다" 의미
15. **distinguish - differentiate**: 모두 "구분하다" 의미
16. **diverse - varied**: 모두 "다양한" 의미
17. **emphasis - stress**: 모두 "강조" 의미
18. **enhance - improve**: 모두 "향상시키다" 의미
19. **ensure - guarantee**: 모두 "보장하다" 의미
20. **estimate - calculate**: 모두 "추정하다" 의미

## 학습 팁 (디시 갤러리 + 정재현 결합 전략)

### 1단계: 기초 어휘 암기 (1주)
- 정재현 필수 기초 300개 먼저 학습
- 매일 30-40개씩 학습
- 동의어/반의어 함께 정리

### 2단계: 기출 7개 풀이 (2-3주)
- 기출문제집 1-2회분씩 풀기
- 모르는 단어 즉시 정리
- 문맥에서의 의미 파악

### 3단계: 동의어 정복 (1주)
- TOP 20 동의어 쌍 집중 암기
- 각 쌍의 미세한 뉘앙스 구분
- 기출에서 실제 사용 사례 확인

### 4단계: 최종 점검 (3-4일)
- 약한 부분 재학습
- 모의고사 1-2회 풀이
- 시험 전날 긴급 단어 30개 암기
